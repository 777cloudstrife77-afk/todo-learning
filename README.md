# Todo 清单

一个简单的本地待办事项网页，用来记录任务并跟踪完成情况。无需安装依赖或启动服务器，直接用浏览器打开 `index.html` 即可使用。

## 已有功能

- 输入任务并点击“添加”创建待办事项；空白输入不会添加，添加成功后输入框会清空。
- 点击任务旁的“完成”标记为已完成，文字会变灰并显示删除线；点击“撤销完成”可恢复未完成状态。
- 点击“删除”移除对应任务。
- 使用浏览器的 `localStorage` 保存任务及完成状态，刷新页面后仍会显示。

## 使用的技术

- **HTML**：页面结构和输入表单（`index.html`）。
- **CSS**：页面布局、按钮及完成状态样式（`styles.css`）。
- **原生 JavaScript**：任务交互和 `localStorage` 数据读写（`script.js`）。

项目未使用框架、第三方依赖或后端服务。数据保存在当前浏览器的本地存储中，不会自动同步到其他浏览器或设备。
